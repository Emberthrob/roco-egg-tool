# 洛克王国智能配窝器

> 帮助《洛克王国》玩家配窝、计算后代与遗传的网页辅助工具。纯前端、无后端，数据保存在浏览器本地。

---

## 一、这是什么

一个帮你在《洛克王国》里更高效「孵蛋」的工具，核心解决三件事：

1. **配窝**：根据你仓库里的雌雄精灵，自动推荐最优的雄性配对方案，并生成精灵窝位置图。
2. **计划孵化路线**：设定一个目标精灵（种族 + 性格 + 身体奖牌 + 声音奖牌），自动算出一条「从现有精灵到目标精灵」的遗传/传递路线，可视化展示每一代怎么配。
3. **仓库与图鉴管理**：管理你拥有的精灵，搜索、筛选、导入导出。

---

## 二、主要功能

### 1. 精灵仓库（`/storage`）
- 添加 / 编辑 / 删除精灵，支持备注。
- 筛选：蛋组、性别、异色、性格（或按性格增益）。
- 「上次录入」：记录最近一次添加的一批精灵，可快速修改、确认、撤回。
- 导入 / 导出配置（含仓库 + 孵蛋窗口方案），方便备份与迁移。
- 清空仓库（会联动清理相关占用）。

### 2. 精灵大全（`/pet-dex`）
- 按蛋组、赛季异色、已拥有筛选，搜索支持进化链扩展。
- 查看每个种族的拥有数量，详情弹窗可一键「添加入库」。
- 未知组（蛋组 1）不可生育，不可选择。

### 3. 孵蛋配窝（`/breeding`）
- 多窗口（≤5），每个窗口独立设置窝数、雌性、筛选条件。
- 按性格或性格增益筛选雄性。
- 一键生成配窝方案，并生成位置图（支持重新布局、拖拽、导出 PNG）。

### 4. 配窝计划 / 孵化路线（`/inheritance`）
- 录入目标精灵（种族 + 性格 + 身体/声音奖牌），右上角可勾选「拥有学院精灵窝」。
- 点击「生成孵化路线」，可视化展示从仓库现有精灵一路「传递 / 合并 / 回交」孵化出目标精灵的完整步骤。
- 每个块（阶段）显示父本、母本、回交副本、子代、阶段目标，并用颜色标注特征遗传情况；块内非仓库精灵模块显示其进化链最低形态。
- 仓库缺中间精灵时，会显示黄色「问号」模块，点击可补录精灵（最终块缺母本直接填表、种族锁定）。
- 点击「阶段目标」/「目标」模块，可把该精灵加入仓库（目标模块会先选性别）。
- 「母本过滤」开关：开启后，不同窗口/不同路线从仓库选用的雌性不会重复。
- 孵蛋队列：点击块右上角「加入队列」，暗化界面后点选块，按父本分组、可分配学院窝，最后「加入精灵窝」批量生成只读配窝窗口。
- 仓库里删改精灵后，会只重新生成受影响的窗口路线。

---

## 三、快速上手

1. 进入「精灵仓库」，先把你拥有的精灵录入进去（或导入之前的配置）。
2. 想直接配窝：去「孵蛋配窝」，添加雌性，点生成方案。
3. 想孵化指定目标：去「配窝计划」，录入目标精灵，点「生成孵化路线」。

> 数据都存在浏览器 `localStorage` 里，换设备 / 换浏览器前记得在「精灵仓库」里**导出配置**备份。

---

## 四、数据与备份

- 所有数据保存在浏览器本地（`localStorage`），不联网、不上传。
- 备份方式：精灵仓库页「导出」，得到 `用户精灵配置-YYYY-MM-DD.json`；之后可在任意设备「导入」恢复。
- 清理浏览器缓存会清空数据，请定期导出备份。

---

## 五、常见问题

- **换设备数据没了？** 需要先在旧设备「导出」，再到新设备「导入」。
- **生成方案没有结果？** 检查仓库里是否录入了满足条件的精灵；部分路线会显示「问号」模块，代表需要先补录中间精灵。
- **性别只有雄/雌的精灵？** 交配时会自动排除不符合性别的种族。
